# Simple Live

简简单单的看直播

一款基于 Flutter 的多平台直播聚合观看应用，支持多个主流直播平台，界面简洁、开箱即用。

## 功能特色

- **多平台聚合**：一站观看多个主流直播平台内容，无需在多个 App 之间来回切换
- **简洁界面**：清爽的 UI 设计，支持浅色 / 深色模式
- **弹幕支持**：完整弹幕解析与展示
- **收藏与历史**：方便管理常看的主播
- **支持**：Android

## 下载安装

### Android

- 前往 [Releases](https://github.com/a298016220666/Simple-livestream/releases) 页面下载最新 APK
- 直接安装 `Simple_Live_*.apk` 即可（已签名，无需额外操作）

> 注：本仓库提供的是定制版安装包，开箱即用。

## 使用说明

1. 打开 App，在首页选择直播平台
2. 浏览或搜索直播间
3. 点击进入直播间观看，支持弹幕互动
